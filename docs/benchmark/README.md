| P17 | Medium | `wild:*.txt` glob-trigram 冷启动异常 |

## 优化建议

1. **放宽 trigram 降级阈值** `totalSize/67` → `totalSize/20`（P0，最高优先级）
2. **Regex 查询提前终止**（P2）
3. **内容搜索直接查内容索引**（P3）
4. **date filter 支持**（P4）
5. **多词查询独立 trigram + 交集**（P5）
6. **Flush/启动后预热**（P16/P17）
